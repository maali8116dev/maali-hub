# MAALI Landing Copy Expansion

**Purpose:** Draft landing-page copy that keeps everything Maali already does (opportunities hub, membership, applications, reviews, mentors, resources, multi-sector Africa focus) and **adds** the GAT / flyer narrative (Activate → Optimise → Scale, readiness, informal-to-investable pathway).

**Sources:** `docs/GAT-MAALI Presentation.pptx`, `docs/MAALI Tri-Fold Flyer.pdf`  
**Principle:** Expansion, not replacement. Nigeria agri is a flagship use case, not the whole brand.

**Status:** Copy draft only. Do not paste loan rates into live UI until product/legal confirm those products are live on maalihub.com.

---

## 1. Positioning (expanded)

### One-line (hero-ready)

**From informal activity to investable opportunity**, one hub to discover funding, jobs, learning programs, and enterprise support across Africa.

### Short paragraph

MAALI helps African talent grow. Founders, farmers, traders, professionals, students, and interns use one platform to find opportunities, build readiness, and apply with confidence. Born from community finance practice and expanded into a formal opportunity network, including a pathway for agribusiness and productive enterprise where partners offer finance and development support.

### What we keep from today

- Multi-sector opportunity marketplace (grants, jobs, internships, trainings, scholarships, fellowships, accelerators, and more)
- Community (free browse) + Full Member (apply)
- Guided applications, documents, review workflow
- Mentors, resources, blog, success stories
- Pan-African, multilingual, mobile-first

### What we add from GAT / flyer

- Journey frame: **Activate → Optimise → Scale**
- Message: informality ≠ lack of potential
- Enterprise readiness (records, cash flow, eligibility, bankable profile)
- Partner complementary bridge: skills → opportunity → capital → documented performance
- Flagship agri / Nigeria / youth-in-agribusiness pilot language (as a spotlight, not the whole site)

### What stays “partner / pilot” (don’t overwrite live $2 membership story)

Flyer/deck cite ₦3,000 membership, revolving fund, and facility rates. Live platform today uses **Community + Full Member ($2/mo)** for opportunity applications. Treat revolving-fund / small-ticket finance as a **GAT productive-finance pathway** (or future product line), not as a silent replace of current membership copy.

**Important:** The deck media folder is mostly **logos**, not lifestyle illustrations. The tri-fold’s journey diagrams / icons live in the PDF layout, export those from the design source (Canva/Figma/AI), don’t screenshot the PDF for production.

PDF panels (Activate / Optimise / Scale, revolving fund) → export as SVG/PNG for the journey section once you have the editable file.

### Recommended placement on the landing page

1. **Hero visual plane (full-bleed)**  
   - Best single strong photo/illustration of African enterprise (not a collage).  
   - Prefer a versatile scene (market, workshop, farm+phone, co-working) so it reads multi-sector.  
   - If agri-only, use on the **Spotlight** band instead of the main hero.

2. **Activate → Optimise → Scale strip**  
   - Three equal illustrations or icons from the deck, one per stage.  
   - Keep text dominant; art supports the journey (matches flyer “How it works”).

3. **Audience / “Who it’s for” row**  
   - Deck audience tiles (farmers, traders, agripreneurs, small businesses) → expand tiles to also show founder, professional, student.  
   - Either redraw icons in one style, or use 2-3 deck arts + 2-3 new icons so agri isn’t 100% of the row.

4. **Trust / partner strip**  
   - Logos only (GAT, IITA, others), don’t stretch photos here.

5. **Do not**  
   - Don’t paste entire tri-fold PDF as a homepage image.  
   - Don’t overlay floating badges/stats stickers on hero media (site design rules).  
   - Don’t use loan-rate tables as decorative graphics on the public hero.

### Technical steps

```text
1. Open docs/marketing-assets/*.png, pick hero + 3 journey images.
2. Optimise (WebP/AVIF, ~1200-1600px wide for hero).
3. Place in public/images/landing/ (e.g. hero.webp, journey-activate.webp, …).
4. Wire in HeroSection / HowItWorks / new Progression section.
5. Add alt text that is multi-sector aware (“Member profiling on MAALI”) not only “Nigerian farmer loan”.
```

### If art is too agri-specific

- Keep agri art for Spotlight + Resources/About.  
- Commission or source 1-2 additional images for Tech / Career so the first viewport isn’t sector-locked.  
- Reuse deck **diagrams** (journey arrows, revolving-fund schematic) as simplified SVG icons, high clarity, brand-safe.

### Revolving-fund / product diagrams

Use on **Partners / About / Finance pathway** pages once that product is public, not as the primary homepage metaphor until live membership messaging stays accurate.
